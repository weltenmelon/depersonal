Набор программного кода на Python разработанный в ходе подготовки ВКР на тему "Разработка методики и программного средства обезличивания персональных данных для использования в моделях машинного обучения"

Использует методы обезличивания, оценки качества обезличивания и проверки полезности данных для обучения моделей ИИ на табличных данных. 

Задействованы библиотеки polars, numpy, scikit learn

depersonal_lib/

├── core/

│   ├── privacy_models.py       # Модели конфиденциальности (k, l, t)

│   ├── transformations.py      # Методы преобразования

│   └── utils.py                # Проверка полезности

examples/                # Примеры использования в Jupyter Notebook

Набор программного кода на Python разработанный в ходе подготовки ВКР на тему "Разработка методики и программного средства обезличивания персональных данных для использования в моделях машинного обучения"

> Программа официально зарегистрирована в Федеральной службе по интеллектуальной собственности (Роспатент). Свидетельство о государственной регистрации программы для ЭВМ № 2026661116 от 17 апреля 2026 г.
> Правообладатель: ФГАОУ ВО «Балтийский федеральный университет имени Иммануила Канта».
> Посмотреть документ: [свидетельство о регистрации](Свидетельство%20о%20регистрации%20ПО.pdf)


Текст ВКР в файле: [ВКР Титов](ВКР%20Титов.docx)

Использует методы обезличивания, оценки качества обезличивания и проверки полезности данных для обучения моделей ИИ на табличных данных. 

Пример использования кода: [testing depersonal](examples/depersonal_lib/core/testing%20depersonal.ipynb)

Задействованы библиотеки polars, numpy, scikit learn

│   ├── transformations.py      # Методы преобразования

│   └── utils.py                # Проверка полезности

└── testing depersonal.ipynb

examples/                # Примеры использования в Jupyter Notebook
